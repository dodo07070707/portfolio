## 개요

> 사용자의 클릭이 안전하도록, 사이트 접속 전의 위험을 정찰합니다.

사용자의 웹 서핑 과정에서 URL 및 웹 페이지 정보를 수집하여 AI 기반으로 피싱 위험도를 실시간으로 분석하는 Chrome Extension입니다.

- 팀: 한정판콩국수 (구본찬 · 김도윤 · 이현명 · 조성민)
- 담당: Frontend

## 시스템 구성

| 영역      | 기술             |
| --------- | ---------------- |
| Front-end | React            |
| 플랫폼    | Chrome Extension |
